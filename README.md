# Welcome to Card Captor Ragnarok Online!

Welcome to the ultimate community wiki and beginner guide for **Card Captor Ragnarok Online**, a fast-paced seasonal private server. 

## What is a Seasonal Server?
Unlike traditional servers, Card Captor RO runs on **3-month seasonal cycles**. Every three months, the server undergoes a complete reset, giving all players a fresh start and a level playing field to compete for top rankings, economy dominance, and ultimate gear.

## Purpose of this Guide
Whether you are a veteran returning for the new season or a complete newcomer stepping into the world of Ragnarok for the first time, this guide is designed to help you:
* Understand custom seasonal mechanics and resets.
* Find the best leveling spots and efficient progression routes.
* Discover customized card synergies and class builds.

Use the sidebar navigation to explore the different sections and get ready for Day One!
